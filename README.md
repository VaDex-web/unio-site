# Унио — сайт

Сайт приложения Унио для студентов ДГТУ. Обычный HTML, CSS и JS без сборки.

- `index.html`, `style.css`, `main.js` — страница.
- `map/` — 3D-карта корпусов из приложения.
- `privacy/` — политика конфиденциальности.

Посмотреть у себя: `python3 -m http.server` в этой папке и открыть http://localhost:8000.
